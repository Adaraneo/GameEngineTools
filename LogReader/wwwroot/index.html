    Zelená = fyziologické akce (Eat, Drink, SelfCare) Modrá = sociální (ReachOut, InviteIntimacy) Fialová = odpočinek (Sleep, MoveToRest) Šedá = ostatní (Idle, Work, Create)

    Goals — kategorie
    Fialová = Existential (FindMeaning, OvercomeTrauma, BuildIdentity) Červená = Survival (ProtectFamily, EscapeDanger) Oranžová = Career (MasterCraft, BuildReputation) Růžová = Relational (FindPartner, RepairRelationship, SeekRevenge)
    Resolution: ✅ Completed — dosaženo 🚫 Abandoned — vzdáno (frustration) 🌫️ Faded — vyprchalo (salience klesla na 0) 🔀 Displaced — nahrazeno jiným cílem
    Interactions — výsledky
    P% = pravděpodobnost přijetí interakce vypočtená enginem (z Closeness, Comfort, Stress, Noise…)
    ✅ accepted — interakce přijata, vztah se mění pozitivně
    ❌ rejected — interakce odmítnuta, potenciálně negativní dopad
    Driving Need = nejvyšší potřeba v momentě akce (kauzální kontext)
    Relationships — dimenze
    Bary 0–100. Barva v matici: zelená >80, modrá 50–80, šedá 20–50, červená <20.
    Warm / Reliable / Emo. Safe = pozitivní přesvědčení (evidencí podložená) Critical / Rejecting = negativní přesvědčení
    Přerušované čáry v grafu = IntimateAffinity, SexualInterest, Familiarity, Attraction (loguje se méně často než core 5 dimenzí).
    Memory — epizodické vzpomínky
    Salience bar 0–1 = důležitost vzpomínky (ovlivňuje decay a vliv na chování). Barva badge = emocionální tón vzpomínky (zelená=Joy/Positive, červená=Anger/Negative, modrá=Sadness…).
